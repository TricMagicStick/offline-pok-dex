# offline-pokédex

A beautiful, fully offline-capable Pokédex web app with an anime-inspired red theme.

## Features (v1)
- Search by name or National Dex number
- Filter by type (multi-select)
- Sort by Dex number, name, HP, or Attack
- Click any Pokémon for a detailed view with stats visualization
- Works completely offline after first load (PWA-ready foundation)
- Clean anime/Pokédex red aesthetic

## Data
Currently includes the first 15 Pokémon with accurate stats and abilities sourced from Serebii.

Future updates will add:
- Full National Dex
- Sprites
- Pokédex entries
- Move lists
- Evolution chains

## How to use locally
Just open `index.html` in any modern browser.

## Deployment
Deployed to GitHub Pages. The app is designed to be installed as a Progressive Web App.

Built with vanilla HTML, CSS, and JavaScript for maximum offline reliability and simplicity.
